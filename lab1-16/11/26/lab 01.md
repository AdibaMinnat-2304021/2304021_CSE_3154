Experiment No: 01
Experiment Name: Introduction to the Web Programming Lab, Course Overview and GitHub
1. Objectives
The main objectives of this experiment were:
•	To become familiar with the Web Programming Lab and its activities.
•	To learn about the programming languages and technologies required for the course.
•	To understand the basic functions of GitHub and its importance in managing projects.
•	To gain knowledge about the course syllabus and learning sequence.
•	To understand the requirements and purpose of the final project.

1.1 Introduction
Web programming is the process of developing websites and web-based applications. In this experiment, we were introduced to the Web Programming Lab and learned about the topics that will be covered throughout the semester. Our teacher discussed the necessary programming languages, development tools, course requirements, and the importance of completing a final project. Although we did not perform any coding activities during this class, it helped us understand the basic structure and purpose of the course.

1.2 Technologies Introduced
During the introductory session, we learned about four important technologies that will be used to develop websites and web applications.
HTML (HyperText Markup Language): HTML provides the basic framework of a website. It allows developers to organize content using elements such as headings, paragraphs, hyperlinks, images, lists, tables, and forms.
CSS (Cascading Style Sheets): CSS is responsible for the visual appearance of web pages. It is used to customize colors, text styles, backgrounds, margins, spacing, and page layouts. It also helps websites adjust to different screen sizes.
JavaScript: JavaScript adds interactive features to websites. It enables web pages to respond to user activities, validate information entered into forms, display messages, and modify page content dynamically.
PHP (Hypertext Preprocessor): PHP is a server-side programming language used to perform operations that take place on a web server. It can process submitted form information, execute application logic, and communicate with databases to store or retrieve data.
1.3 GitHub
GitHub was introduced as a platform for storing, managing, and sharing programming projects. It works with Git, a version control system that records changes made to files over time. By using GitHub repositories, students can organize their source code, maintain different versions of their work, and collaborate with other developers. It also provides a convenient way to publish and submit practical assignments. Learning GitHub at the beginning of the course will help us manage our lab activities more efficiently.
1.4 Course Outline
The course outline was discussed to give us an understanding of the topics we would study during the semester. The learning process will start with HTML for creating web page structures, followed by CSS for designing and arranging page elements. After that, JavaScript will be covered to introduce client-side programming and interactive features. Finally, PHP will be used to understand server-side operations and the development of dynamic websites.
1.5 Final Project
A final project must be completed and submitted at the end of the sessional course. The project will provide an opportunity to apply the concepts and practical skills gained throughout the semester. It is expected to combine HTML, CSS, JavaScript, and PHP to create a functional web-based application. Completing this project will help us understand how different web technologies work together to develop a complete website.
2. Discussion
The introductory experiment helped me understand the learning objectives and practical requirements of the Web Programming Lab. I learned that website development involves several technologies, each performing a different task. HTML organizes the content, CSS improves the design, JavaScript provides interactive functionality, and PHP manages server-side processing. I also understood how GitHub can simplify code management and help maintain a record of project development. Since the course includes a final project, practicing each technology from the beginning will be important for developing the necessary skills and completing the project successfully.
3. Conclusion
In conclusion, this experiment provided an overview of the Web Programming Lab, its course contents, the technologies involved, and the role of GitHub in software development. It also clarified the expectations for the final project. The knowledge gained from this session will serve as a foundation for the upcoming practical experiments and help me develop the skills needed to build web applications.
